2026 Hackathon

La Vaca

Hackathon | Pagos divididos con Interledger

La Vaca es una app para dividir la cuenta del restaurante y cobrar cada parte de verdad. En lugar de calcular quién debe qué, mueve el dinero: el anfitrión crea la cuenta, se genera un QR y cada comensal paga su parte directamente desde su wallet a la del restaurante.

Construida durante una hackatón, usa la API de Open Payments (Interledger) para que varios pagos converjan en una sola cuenta sin que la app custodie los fondos. La barra de progreso se llena en tiempo real y al llegar al 100% la cuenta se cierra con su recibo detallado.

React TypeScript Tailwind CSS Vite Node.js Express Interledger / Open Payments

2026 SaaS

Panello

Proyecto propio | Plataforma multi-tenant para negocios

Panello es una plataforma de gestión para pequeños negocios: cada uno tiene su panel privado para administrar productos, categorías, menús del día, descuentos, pedidos, venta en caja y reportes, además de una tienda pública propia a la que se llega por su slug.

El proyecto está construido con arquitectura multi-tenant, aislando los datos de cada negocio con Row Level Security en Supabase, autenticación JWT y roles de dueño y empleado. Aquí trabajo backend, modelo de datos, seguridad y sistema de diseño.

FastAPI Python React / Expo Supabase PostgreSQL JWT Multi-tenant
Ver Panello Ver repositorio
2026 Caso real

Grandpa Burgers

Tienda en producción | Menú digital conectado a Panello

Grandpa Burgers es la tienda pública de un negocio real funcionando sobre Panello. Es el menú digital que ve el cliente: categorías, productos con foto, variantes obligatorias y opcionales, carrito y pedido por WhatsApp con recogida en tienda o domicilio.

Todo lo que se muestra sale del panel de Panello y todo pedido que entra vuelve a él, donde el negocio lo confirma o rechaza. Es la prueba de que la plataforma funciona de punta a punta con un cliente real.

Next.js TypeScript Tailwind CSS Panello API Supabase WhatsApp
